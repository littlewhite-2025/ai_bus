這次做好了網頁的部分

具體來說是做了:
- 使用React + Vite架構做了網頁，方便前端開發與後續維護，也比較方便去處理互動與視覺效果，
  其中，使用Fastapi來做後端使網頁更新，也使用了Docker包裝好環境，
  因此到了其他地方只需要:
  ```
  docker load -i test2-images.tar
  docker compose up -d
  docker compose logs cloudflared
  ```
  即可打開網站，這時候是使用cloudflare作內網穿透，因此只要取得該網址，其他人就可以連線查看網站，不過目前是臨時網址，所以每次啟動後網址可能會不同。

另外，我在本地的話是直接
```
docker compose up -d
docker compose logs cloudflared
```
(要記得有wsl和docker destop)

或
```前端
npm install(第一次)
npm run dev
```

```後端
python server.py --model runs/detect/seat_detector-3/weights/best.pt --calibration seat_calibration.json --image assets/pictures/main/main2.png
或
python 26.7.20/run_camera_detect.py --model runs/detect/seat_detector-3/weights/best.pt --camera 0
```
