首先先說明`輸出occupied_seats格式`的部分，
格式為:

```json

{
  "occupied_seats": {
    "A01": "empty",
    "A02": "empty",
    "A03": "empty",
    "A04": "empty",
    "A05": "empty",
    "A06": "empty",
    "A07": "empty",
    "A08": "empty",
    "B01": "empty",
    "B02": "empty",
    "B03": "empty",
    "B04": "empty",
    "B05": "empty",
    "B06": "occupied",
    "B07": "empty",
    "B08": "empty"
  },
  "occupied_count": 1,
  "total_seats": 16,
  "person_count": 1
}

```
- empty: 表示空座位（未被占用）
- occupied: 表示座位已被占用

occupied_count是被占用的統計
total_seats為目前設定的座位總數。新增的座位校正程式會依照此預設值輸出各座位座標，若偵測出的座位數量與預設值不同，則可能造成座位排序或座標對應錯誤，需要重新進行座位校正。
person_count是指人數統計


具體可以看上方提到的`# 說明.md`

接下來是`AI偵測流程說明`:

主要用到的檔案為之前傳的`test.py`
我這裡會再附上一份`test.py`並標上註解，具體的話看目錄下的`test.py`
裡面的內容可能會與之前(26.7.13)的 `ex.py`有點類似，畢竟一樣是講偵測流程的，但這次不同的是模型與更多設定都有些不同。

這主要的流程為: 載入模型(best.pt)→讀取圖片(main2.png)→YOLO分析圖片→找出 Person、Seat→畫出框線與標籤→儲存辨識結果。
具體流程在`test.py`的檔案中，為了避免只有看到這個檔案，我把裡面的內容搬到這邊(內容是一樣的)

```python
# 從 Ultralytics 匯入套件中的 YOLO 類別
#這裡主要用於用於建立YOLO模型物件，可用來進行物件偵測、模型訓練、驗證等等的操作。
from ultralytics import YOLO

# 載入訓練完成的模型
# best.pt 是 YOLO 在訓練過程中表現最佳(Best) 的權重檔案，這個檔案包含了模型的結構和學習到的權重參數，因此可以直接用來辨識新的圖片。
model = YOLO("runs/detect/seat_detector-3/weights/best.pt")

# 使用模型對指定圖片進行物件偵測
model.predict(
    # source為指定要辨識的圖片，也可以改成影片，網路串流、攝影機、資料夾路徑，這裡使用的是本地端的圖片路徑。
    source="D:/test2/assets/pictures/main/main2.png",

    # save=True表示將偵測結果儲存下來，通常會存到runs/detect/predict/，如果已經存在同名檔案，會在後面加上2, 3, 4....以此類推
    save=True,

    # conf 表示信心值門檻
    # 框框上方顯示的是模型對該物件的信心度，只有當信心度大於0.23時才會將該物件顯示在偵測結果中。
    conf=0.23
)
```
